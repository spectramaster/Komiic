## 系统简介

### 什么是BioChroma？

BioChroma是一个革命性的身份验证系统，它将你的生物特征转换成独一无二的3D彩色动态验证码。

**主要特点**：
- 🎨 每个人生成的验证码都不同
- 🔒 高安全性，难以伪造
- ⚡ 快速识别（<0.5秒）
- 🌍 跨平台支持

### 如何工作？

```
你的面部 → 摄像头采集 → 特征提取 → 生成3D粒子云 → 显示验证码
                                                        ↓
                                                  其他设备扫描验证
```

## 安装与配置

### Windows平台

1. **下载安装包**
   - 访问 [官网下载页](https://biochroma.dev/download)
   - 选择 `BioChroma-Windows-x64.zip`

2. **解压并运行**
   ```powershell
   # 解压到任意目录
   Expand-Archive BioChroma-Windows-x64.zip -DestinationPath C:\BioChroma

   # 运行应用
   C:\BioChroma\BioChroma.Desktop.exe
   ```

3. **配置摄像头权限**
   - 打开 `设置` → `隐私` → `摄像头`
   - 确保 "允许应用访问你的摄像头" 已开启
   - 在应用列表中找到 `BioChroma`，勾选允许

### macOS平台

1. **下载DMG文件**
   - 下载 `BioChroma-macOS.dmg`
   - 双击打开

2. **安装应用**
   - 将 `BioChroma.app` 拖拽到 `应用程序` 文件夹
   - 首次运行时，右键点击 → "打开"（绕过安全检查）

3. **授予摄像头权限**
   - 首次启动会弹出权限请求
   - 点击 "好" 允许访问摄像头

### Linux平台

1. **安装依赖**
   ```bash
   # Ubuntu/Debian
   sudo apt install libavcodec-dev libavformat-dev v4l-utils

   # Fedora
   sudo dnf install ffmpeg-devel v4l-utils
   ```

2. **下载并运行**
   ```bash
   # 下载AppImage
   wget https://biochroma.dev/download/BioChroma-Linux-x64.AppImage

   # 添加执行权限
   chmod +x BioChroma-Linux-x64.AppImage

   # 运行
   ./BioChroma-Linux-x64.AppImage
   ```

## 生成验证码

### 第一次使用

1. **启动应用**
   - 双击 BioChroma图标
   - 等待应用加载（约2秒）

2. **点击"生成验证码"按钮**
   - 位于左侧面板
   - 按钮显示为 🎬 图标

3. **允许摄像头访问**
   - 如果是首次使用，会弹出权限请求
   - 点击"允许"

4. **调整位置**
   ```
   最佳拍摄距离: 30-50cm
   光线要求: 充足的自然光或室内灯光
   背景: 建议纯色背景
   ```

5. **等待采集**
   - 保持面部在画面中央
   - 等待2秒（系统自动采集）
   - 听到"滴"的一声表示采集完成

6. **查看验证码**
   - 右侧会显示生成的3D粒子云
   - 粒子会自动旋转、呼吸动画
   - 每个人的粒子颜色和分布都不同

### 高级选项

#### 调整粒子数量
```
设置 → 渲染选项 → 粒子数量

推荐值:
- 性能优先: 128粒子
- 平衡: 256粒子（默认）
- 质量优先: 512粒子
```

#### 保存验证码
```
右键点击验证码 → 另存为图像

注意: 保存的是当前帧的静态图像，
      无法用于验证（需要动态扫描）
```

## 扫描验证

### 基本步骤

1. **进入扫描模式**
   - 点击右侧面板的"扫描验证"按钮
   - 摄像头会自动启动

2. **对准验证码**
   ```
   距离: 20-40cm
   角度: 正面拍摄，避免倾斜
   光线: 确保屏幕足够亮
   ```

3. **等待识别**
   - 系统会自动捕获5帧图像
   - 识别过程约0.5秒
   - 进度条显示当前状态

4. **查看结果**
   - ✅ **验证成功**: 显示绿色对勾，展示用户信息
   - ❌ **验证失败**: 显示红色叉号，提示错误原因

### 验证结果详情

**成功时显示**:
```
✅ 验证成功！

用户ID: user_12345
置信度: 97.3%
验证时间: 482ms
时间戳: 2秒前
```

**失败时显示**:
```
❌ 验证失败

原因: 时间戳过期
建议: 请重新生成验证码
```

## 常见问题

### Q1: 为什么我的验证码生成很慢？

**A:** 可能的原因：
1. 摄像头分辨率过高
   - 解决: 设置 → 摄像头 → 分辨率 → 选择640x480

2. 粒子数量过多
   - 解决: 降低到256粒子

3. 电脑性能较弱
   - 解决: 关闭其他占用GPU的程序

### Q2: 验证码有效期是多久？

**A:** 默认30秒

```
原因: 防止截图攻击
修改: 设置 → 安全选项 → 时间窗口
范围: 5-60秒
```

### Q3: 我可以一次生成多个验证码吗？

**A:** 可以，但同时只能显示一个

```
操作: 设置 → 高级 → 批量生成模式
用途: 适合需要频繁验证的场景
```

### Q4: 验证码能在不同设备间使用吗？

**A:** 可以！

```
场景: 在设备A生成 → 设备B扫描验证
要求: 两台设备共享同一个密钥

配置: 设置 → 同步 → 导出/导入密钥
```

### Q5: 我的摄像头无法启动怎么办？

**A:** 检查清单：
1. ✅ 摄像头是否被其他应用占用？
2. ✅ 权限是否已授予？
3. ✅ 摄像头驱动是否正常？
4. ✅ 尝试重启应用

## 故障排除

### 问题1: 摄像头画面卡顿

**症状**: 预览窗口帧率低，画面不流畅

**解决方案**:
```
1. 降低摄像头分辨率
   设置 → 摄像头 → 640x480

2. 关闭其他占用摄像头的应用
   任务管理器 → 查找并关闭

3. 更新摄像头驱动
   设备管理器 → 摄像头 → 更新驱动
```

### 问题2: 验证码识别失败率高

**症状**: 经常显示"验证失败"

**解决方案**:
```
1. 改善光线条件
   - 增加光源
   - 避免逆光

2. 调整扫描距离
   - 距离屏幕30-40cm
   - 确保验证码完整在画面内

3. 清洁摄像头镜头
   - 用软布擦拭镜头
```

### 问题3: 应用无法启动

**症状**: 双击图标无反应

**解决方案**:
```
Windows:
1. 检查.NET Runtime是否安装
   下载: https://dotnet.microsoft.com/download

2. 以管理员身份运行
   右键 → 以管理员身份运行

macOS:
1. 检查是否被隔离
   sudo xattr -rd com.apple.quarantine BioChroma.app

2. 查看系统日志
   控制台.app → 搜索"BioChroma"

Linux:
1. 检查依赖
   ldd BioChroma.Desktop

2. 查看错误日志
   ./BioChroma.Desktop --verbose
```

### 问题4: 粒子渲染异常

**症状**: 粒子不显示或颜色错误

**解决方案**:
```
1. 更新显卡驱动
   NVIDIA: GeForce Experience
   AMD: AMD Software
   Intel: Intel Driver Update

2. 切换渲染后端
   设置 → 渲染 → 后端 → 选择OpenGL/DirectX/Metal

3. 重置设置
   设置 → 高级 → 恢复默认设置
```

## 安全提示

⚠️ **重要安全建议**

1. **不要截图分享验证码**
   - 验证码包含你的身份信息
   - 截图可能被他人利用

2. **保护你的密钥**
   - 密钥存储在: `~/.biochroma/keys`
   - 定期备份密钥文件

3. **注意使用环境**
   - 避免在公共场所生成验证码
   - 确保周围无陌生人

4. **定期更新应用**
   - 新版本包含安全补丁
   - 设置 → 更新 → 检查更新
